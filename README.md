Portfolio personal de Saúl Moreyra — Next.js 15, React 18, Emotion, next-intl.

## Requisitos

- Node.js 24.x (ver `.nvmrc`)
- Yarn 1.22.x

## Instalación

```bash
nvm use
yarn install
```

## Desarrollo

```bash
yarn dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Build

```bash
yarn build
yarn start
```

## Deploy en Vercel

- **Node.js Version:** 24.x
- Vercel detecta `yarn.lock` y usa Yarn automáticamente.
